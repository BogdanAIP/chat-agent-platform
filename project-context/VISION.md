# Vision

Let ordinary ChatGPT use the user's own computer as a modular, professional tool surface without forcing a second AI runtime, a custom cloud backend or a monolithic local agent.

The bridge should stay boring and replaceable: official Secure MCP Tunnel, a replaceable MCP runtime, and the best available MCP backend for each local capability.

Capability growth should not mean plugin growth or permanent process growth. Prefer one stable Chat-facing contract, a pre-approved local backend catalog, and task-driven activation of only the capabilities a workflow needs.
